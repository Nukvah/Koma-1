where these come from

Every top-level folder in /library is a library, found at the next scan. A folder named ~name is that account's own: the libraries in it are seen by that account alone, which also edits their settings.

Until changed here, a library's settings come from its folder: name capitalised; type from the name (manga if it says nothing); direction right to left for manga, left to right otherwise; colour the next in a fixed list. A book's own metadata still wins over the direction.

Changes are kept in the catalogue, not in /library: no file or folder is renamed. koma serve queues them and the worker writes them, so the worker stays the catalogue's only writer.

Only the admin edits the shared libraries; readers and curators see this page read-only, as it is today.
