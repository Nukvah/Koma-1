where these come from

Every top-level folder in /library is a library, found at the next scan.

name: the folder's name, capitalised.

type: from the folder's name (manga, comics, webtoon, cosplay…); manga if it says nothing.

direction: right to left for manga, left to right otherwise. A book's own metadata (ComicInfo.xml, metadata.json) wins over it.

colour: the next one in a fixed list, in folder order.
